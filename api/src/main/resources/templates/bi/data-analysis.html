분석 설계

운영 화면에서는 개별 주문·결제·재고 건을 처리하는 데 집중하고, BI에서는 기간·상품·카테고리 단위의 집계 데이터를 별도로 제공하도록 구성했습니다. 운영 DB를 BI 도구에 직접 연결하지 않고 조회 전용 API를 두어 분석 데이터 제공 영역을 분리했습니다.

매출 분석

주문·취소 데이터를 기준으로 순매출과 객단가 분석

재고 분석

가용재고·안전재고·LOT 유효기간 데이터를 기반으로 부족재고 확인

결제 분석

승인·취소·결과불명 등 결제 상태별 운영 현황 확인
